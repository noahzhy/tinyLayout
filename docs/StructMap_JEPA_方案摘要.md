# 00 · 方案总览

## 一句话

**从手持 RGB 短序列学习局部结构 BEV，让 JEPA 在部分拓扑记忆条件下预测更充分观察所对应的 BEV 表示；用预测一致性进行地点消歧与端口关联，增量构建全局二维拓扑图。**

工作名称：**StructMap-JEPA: Topology-Conditioned BEV Predictive Learning for Visual Layout Mapping**。这是研究方案，不是已有论文或经过验证的产品。

## 输入与输出

输入来自 SAM 类采集：RGB、时间戳，约 2 FPS，可有侧拍、停留、遮挡、暂停及异地续拍。默认单层门店，不假定镜头朝向等于行进方向。IMU、内参可作为未来可选元数据，但不是当前主流程依赖。

输出包括通道口/路口、端口与连接、主通道的支路顺序、货架面侧别与端架、证据引用、未探索边界、未关联组件以及非等比例二维排布。米级坐标、真实最短路、完整货架尺寸不在本轮承诺中。

## 三个核心组件

| 组件 | 回答的问题 | 表示 |
|---|---|---|
| 局部结构 BEV | 当前空间证据如何排列？ | 小型 H×W×D latent，加可见性/支持度 |
| 拓扑条件 JEPA | 候选地点能否解释更充分的实际观察？ | 上下文 BEV + 历史子图 → 目标 BEV latent |
| 全局拓扑图 | 已确认的地点和通道怎样连接？ | 节点、端口、多重边、顺序、边界和事件日志 |

BEV 不是商品纹理的俯视照片；图不是全店密集占据栅格。两者分工：局部保留模糊证据，全局提交可审计关系。

## 主流程

```text
RGB 窗口 + 时间信息
  → 图像编码（缓存）
  → 学习式局部 BEV + 地点描述子
  → 召回历史候选 + 读取先前的局部地图 snapshot
  → 小型 JEPA 预测器 + 方向/端口对齐
  → 与独立观察分支比较结构预测误差
  → EXTEND / ADD_NODE / REVISIT / DEFER 提议
  → 证据门控的增量图更新
  → 非等比例 Store Layout
```

## 拟研究的贡献

**跨视角 BEV 预测：** 学生仅看不完整视角，EMA 教师读取更多真实视角，在同一局部 chart 中形成结构目标；训练不重建 RGB。

**拓扑条件预测关联：** 对少量地点候选读取局部图记忆，预测当前留出观察中的结构；比较实际证据，区分“外观相似但连接不同”的位置。预测器在线保留。

**二维反事实记忆：** 以错误支路顺序、端口排列和货架侧别作为有证据的困难负样本，避免模型只学外观或忽略图记忆。

贡献的有效性和新颖性仍需后续研究。BEV、JEPA、向量图各自不是首次提出，参考边界见 09。

## 关键取舍

不做完整三维重建；不为闭合地图强行合并片段；不把预测自由空间当成通行事实。结构相似不是同一地点，地点相同不意味着存在一条新的路线。采集未包含关键转场时，系统必须能保留未知。

本包提供可验证起点和任务分解，不提供“随机初始化模型即可生成真实门店地图”的假象。
